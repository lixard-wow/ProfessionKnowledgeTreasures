# Profession Knowledge Treasures

Find every profession knowledge treasure in Midnight and always know where to go next. The addon builds a route, points the waypoint at the next treasure, and moves on by itself as you loot.

- **Download:** [CurseForge](https://www.curseforge.com/wow/addons/profession-knowledge-treasures)
- **User guide:** [lixard-wow.github.io/profession-knowledge-treasures](https://lixard-wow.github.io/profession-knowledge-treasures/)
- **Game:** Retail, Midnight
- **Covers:** 88 treasures across 11 professions

## Features
- Shows only treasures for the professions your character has learned.
- Builds a short route from where you're standing, zone by zone.
- Sets the in-game waypoint arrow, plus a TomTom arrow if you use TomTom.
- Tells you which portal to take when the next treasure is in another zone.
- Moves to the next treasure when you loot one, and to the nearest one when you enter a new zone.
- Tracks your progress for each profession.
- Short tips for tricky treasures, including ones hidden by phasing or gated behind a quest or achievement.
- A Darkmoon Faire helper for each profession's monthly +2 knowledge quest, with a step-by-step mini bar.
- Three looks: Artisan's Ledger, Workbench and Lixard Classic.

Zones: Silvermoon City, Eversong Woods, Zul'Aman, Atal'Aman, Voidstorm and Slayer's Rise, and Harandar and The Den.

## Getting started
1. Install the addon and log in.
2. Pick a look in the window that appears. You can change it later with `/pkt theme`.
3. Follow the waypoint arrow to the first treasure and loot it. The waypoint moves on by itself.

Professions not detected? Type `/pkt profs` and pick them yourself.

## Commands
| Command | What it does |
| --- | --- |
| `/pkt` | Show or hide the tracker |
| `/pkt next` / `/pkt prev` | Next or previous treasure |
| `/pkt first` | First treasure on your route |
| `/pkt nearest` | Nearest treasure in this zone |
| `/pkt reload` | Rebuild the route |
| `/pkt list` | List remaining treasures in chat |
| `/pkt mini` | Minimize or expand the tracker |
| `/pkt theme` | Choose your look |
| `/pkt dmf` | Show or hide the Darkmoon Faire helper |
| `/pkt profs` | Pick your professions by hand |
| `/pkt settings` | Open settings |

`/profknowledge` works the same as `/pkt`. Minimap button: left-click for the tracker, right-click for the Darkmoon Faire helper, middle-click for settings.
